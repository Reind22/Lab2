# Lab2 — Привязки, команды и триггеры (WPF)

Лабораторная работа по дисциплине «Программная инженерия»: приложение с пятью
вкладками, демонстрирующими механизмы привязки данных, команд и триггеров WPF.

## Вкладки

- **Привязка по умолчанию** — сравнение прямой привязки к элементу (`ElementName`)
  и привязки через визуальную модель;
- **Двухсторонняя привязка** — режим `TwoWay` с тремя значениями
  `UpdateSourceTrigger`: `PropertyChanged`, `LostFocus`, `Explicit`;
- **Одноразовая привязка** — режим `OneTime`;
- **Односторонние привязки** — режимы `OneWay` и `OneWayToSource`;
- **Триггеры** — `Trigger`, `DataTrigger`, `MultiTrigger`, `MultiDataTrigger`,
  `EventTrigger`.

Все кнопки работают через команды (`ICommand`), обработчики нажатия в разметке
отсутствуют. Исключение — кнопка «Применить роль»: она показывает режим `Explicit`,
где источник обновляется вручную.

## Две реализации MVVM

В репозитории две ветки с одинаковой разметкой и разными реализациями инфраструктуры:

- `manual-mvvm` — собственные `ObservableObject` и `RelayCommand`, без пакетов NuGet;
- `community-toolkit` — та же логика на `CommunityToolkit.Mvvm` 8.4.2 с атрибутами
  `[ObservableProperty]` и `[RelayCommand]`.

Основная ветка `main` содержит вариант с ручной реализацией.

## Требования и сборка

- Windows 10 или 11, .NET 8 SDK (проект собирается как WPF-приложение).

```powershell
dotnet build .\WpfLab2.csproj
```

## Структура

```
MainWindow.xaml            контейнер с вкладками
Views/*.xaml               разметка каждой вкладки в отдельном UserControl
Models/Person.cs           модель данных
ViewModels/                визуальные модели и инфраструктура MVVM
Styles/AppStyles.xaml      стили приложения
```
